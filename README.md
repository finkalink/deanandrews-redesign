# Dean Andrews — site redesign concept

A redesign concept for [deanandrews.com](https://deanandrews.com): an art-first homepage, browsable series with sizes, prices and availability, a lightbox for each painting, installations, commissions and contact.

All artwork and text © Dean Andrews.

It's a single static page (`index.html`) with images in `img/`. No build step: open `index.html` or serve the folder.
